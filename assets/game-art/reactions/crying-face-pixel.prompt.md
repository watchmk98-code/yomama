# Crying reaction sprite

Generated with the built-in image generation tool. The PNG is transparent and
is preloaded on Market, displayed with pixelated scaling and a 0.5-second fade.

## Prompt

Create a single transparent PNG game UI sprite: a cute loudly crying emoji face for YoMama, a child-friendly retro pixel-art business-management game with a black-and-amber interface. Front-facing round amber-yellow face, stepped pixel outline in dark brown, raised worried eyebrows, squeezed-shut eyes, big open dark mouth and two vivid cyan-blue streams of tears. Playful exaggerated disappointment, not disturbing. True low-resolution pixel-art styling, as if drawn on a 32 by 32 pixel grid and enlarged using nearest-neighbor: large consistent square pixel clusters, hard stepped edges, limited palette of amber #ffb000, gold, dark ochre, near-black, cyan and pale cyan. Flat colors, minimal pixel highlights, no smooth curves, gradients, antialiasing, glow, shadow, 3D rendering, text or extra props. Square canvas with the single whole face centered and filling 90% of the canvas, small even transparent margin. Background MUST be genuinely transparent alpha, not a checkerboard illustration. Must be readable when displayed at 64 by 64 CSS pixels. Output only the individual transparent sprite.
