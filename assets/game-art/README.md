# YoMama inventory and control art

Imported unchanged from `yomama_all_batches_zips_1-5.zip`.

- 44 goods icons, three action icons, and two licence badges.
- All sources are transparent 1254 × 1254 PNGs, displayed at 32–44px in the UI.
- Goods match building IDs and normalized resource names in economy.v3.json.
- Batch 4 supplies the selected Bandwidth image; batch 3 also contained an alternate.
- Preserves is absent: its resource name / initial fallback remains visible.
- Construction and celebration effect sheets are not included in this pack.
- The existing animated building sheets remain in ../buildings/spritesheets/.

Icons are loaded lazily; filenames and source pixels are preserved.
